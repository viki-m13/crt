How many options can you exercise before AMT hits?

Exercising incentive stock options and holding them doesn't create income — it creates an AMT preference item. There's a precise number of shares you can exercise each year before that costs you anything. This finds it.

Updated for the 2026 rules. The One Big Beautiful Bill Act moved the AMT exemption phaseout down to $500k / $1M and doubled the phaseout rate to 50¢ per dollar — which creates a band where each extra dollar costs 39–42%, not 26–28%. Most calculators still use the old rules.
