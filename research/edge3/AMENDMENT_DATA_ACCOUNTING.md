All ac_ price-shard Git blob hashes verified; the union of historical S&P membership symbols plus the predetermined twin/fund sets was exported, without screening outcomes. Original risk-free data were also downloaded from Kenneth French's daily factors archive; source zip hashes are recorded. No other repository is modified.

The replication runs the SAME frozen signal definitions and candidate holding periods on independently sourced prices using original historical membership. It is not an untouched research holdout. Dataset completeness, ticker identity, corporate actions and missing prices remain explicit limitations. In particular no longest-lifetime/full-history-completeness filter is allowed. Symbol punctuation aliases are resolved only when unambiguous.

Two simulator issues found in review are corrected for ALL candidates, not selectively: floating residual holdings below 1e-12 NAV are zeroed so numeric dust cannot masquerade as a delisting; entry and expiry orders scheduled for the same instrument/auction are netted BEFORE charging costs (there is no reason to pay for self-cancelling virtual cohort trades). This does not move any signal or expiry time. All virtual lots are still retained for horizon auditing. The earliest logged legacy results charged both sides even when only a net order was required; superseded outputs are preserved, not advertised as final results.

The structural stock pairs' source-wide March 20 cutoff is kept distinct from later ETF observations; comparing both on the earlier common cutoff avoids treating an administrative source stop as a bankruptcy. This is a diagnosed common feed limit, not a filter based on individual forward returns.

## Additional tightly bounded mechanism test

DAILY NETTED INVENTORY TRANSFER: repeat the same economic scores with a one-session decision cadence and overlapping 5- and 30-session fixed-expiry cohorts. Continuously replenishing an existing book may preserve a liquidity edge at much lower NET turnover than isolated entry/exit trades. This is a new cadence ablation registered now, not a claim of a discovered edge. Compare it to the original five-session cadence, with identical costs, timing, risk controls and validation/test boundaries. The 5-session branch is a fast diagnostic, not compliance with the earlier 30-session requirement; the 30-session branch retains that requirement.

Run all predefined models and display every failure. Do not choose configurations from 2021+ results. Validation selects using dates before 2021; fresh test accounts start afterward without hindsight-selected positions. Exact observed RF is used where supplied; the original fixed-3%-RF results remain a scenario, not actual historical excess returns. Base borrow 3%, per-side cost 5bp, no short collateral interest and 2% financing spread remain unchanged. A fixed lower-cost (1bp/1% borrow), higher-cost (10bp/10% borrow), and extra-execution-delay sensitivity applies to pretest-selected candidates, not only to the best test row.
